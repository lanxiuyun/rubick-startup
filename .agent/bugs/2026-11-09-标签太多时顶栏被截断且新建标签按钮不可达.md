# 标签太多时顶栏被截断且新建标签按钮不可达

## 症状

标签超过十几个之后，顶栏标签条被窗口右边切掉：截图上最后一个标签只剩半截（例如 `nc`），既看不到滚动条也没有箭头，`+ 新建标签` 也跟着被推到视口外。

实测（1290px 视口、15 个标签）：标签条 `scrollWidth = 1335`、`clientWidth = 1250`，`#tagAdd` 的 `left = 1327`，完全在视口外。

## 原因

标签条 `overflow-x:auto` 本身能滚，但三条通路都被堵住，等于不能滚：

1. `scrollbar-width:none` + `.tags::-webkit-scrollbar{display:none}` 把滚动条藏了；
2. Chromium 不会把纵向滚轮转成横向滚动，鼠标滚轮在标签条上无效果；
3. 没有箭头或「更多」之类的可点击入口。

`+` 按钮当时和标签在同一个滚动容器里，标签一多就一起被推出视口，连带「新建标签」这个唯一入口失效。

## 修复规则

- 顶栏仍是 53px 单行（不换行）。`+` 与「全部标签」按钮移到滚动容器外的 `.bar-actions`，钉在最右，标签再多也点得到。
- 标签条悬停时下缘显示横向滚动条，外观与列表右侧滚动条一致：`scrollbar-width:thin` + `scrollbar-color`（滑块 `#c5cdd3`、透明轨道，悬停滑块加深 `#8e9ba4`），旧版 Electron 走 `::-webkit-scrollbar` 8px + 2px 透明边内缩；默认透明，`:hover` / `:focus-within` 才显色。
- 纵向滚轮直接加到 `scrollLeft`；`deltaX`（触控板横滑、Shift+滚轮）交给浏览器原生滚动，避免滚动两次。
- 右侧「全部标签」按钮弹出 `Popover`（`.tag-overview-popover`）：两列 grid 列出「全部 + 所有标签」（名称 + 数量），最高 220px、超出滚动。点标签直接筛选并关闭；`Escape`、点外部、开始打字都关闭；打开时 `Enter` 只关闭浮层、不执行命令；浮层里右键标签仍走同一个重命名/删除菜单。
- 选中/新建的标签用 `useLayoutEffect` 滚进可视区；新建标签默认按数量排到最后，不滚过去用户看不到它已经被选中。
- 浮层用 `destroyOnHidden`，关闭时卸载内容，避免搜索/状态残留和 DOM 里出现重复的标签节点。
- 顶栏和浮层共用同一份「右键菜单打开的是哪个标签」状态，用 `from: 'strip' | 'grid'` 区分来源，否则同一个标签会在两边同时弹菜单；打开重命名编辑器时顺手收起浮层，否则编辑器结束后浮层会自己弹回来。

## 验证

`tests/visual.e2e.js` 用 14 个标签 + 800px 视口断言：标签条确实溢出且使用 thin 滚动条、`+` 与「全部标签」按钮完整落在视口内、纵向滚轮能横向滚动、滚到末尾最后一个标签完整可见、浮层列出「全部 + 14」共 15 个标签且不超出视口、浮层 grid 可滚到最后一个标签、点浮层里的标签会变成筛选并关闭浮层、`Escape` 关闭、打字关闭；另外 375px 下断言浮层仍完整可见，1200px 下断言标签条不溢出。

截图：`.visual-qa/tags-overflow-800.png`、`tags-overflow-end-800.png`、`tags-overview-800.png`（裁剪图，整页截图会把浮层和列表分层合成错序）、`tags-overview-375.png`。

顺带修了面板测试的偶发失败：记录标签面板勾选后会把已关联标签排到最前，rc-virtual-list 会重排/卸载行，直接 `check()` 会点到移动中的行。测试改成先在面板搜索框里把目标标签过滤成唯一行再点击，并用保存结果断言。
