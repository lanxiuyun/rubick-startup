# 标签样式与完整 Rubick 窗口截图验收约定

## 功能边界

参考图只用于配色、留白与单行列表排版，不照搬额外搜索框、运行按钮、描述标题、分区标题或资产总数。输入和执行继续复用 Rubick 搜索框。

顶栏环境检查入口和选中命令回显已移除。选择记录只改变行高亮；执行反馈走 toast 和日志。新建、重命名标签的输入态有确认与取消按钮，Escape 也可取消。

## 当前布局与配色

- 用户在三套预览中选定 A「轻盈白底」，不引入侧栏或紧凑分隔线列表。
- `ROW_H = 56`，命令单行显示，28px 图标槽、18px 字形、13px 命令字体。
- 内容区白底 `#fff`，宿主 header 保持原样；不要为了改插件底色去改 Rubick。
- 主题主色采用 Ant Design 蓝 `#1677ff`；选中标签与记录用浅蓝底 `#eaf3ff`，选中标签字色 `#1668dc`、透明边框且无外圈焦点轮廓，不加记录整圈边框。
- 新建标签用 28px 加号按钮，保留 title 和无障碍名称；时间使用 10px 等宽字体。
- 行内标签选定方案 A「无边框柔和色块」：蓝底 `#dceaff`、透明边框、文字 `#245ba5`，26px 高、5px 圆角、12px 字体；滚动条滑块仍使用 `#adc9ef`。
- 标签数量有独立徽标；标签不可变成无法辨认的裸文字。
- 标签切换只改配色，不能改字重、padding、边框宽度，否则会引起宽度跳动。
- 行内删除符独立占位，不允许用绝对定位覆盖标签名。悬停不能遮字或改变布局。
- 删除符默认蓝灰 `#6185b6`；18×18px 正方形区域居中放置 10×10px SVG，清除 Ant Design 图标的偏移。悬停深红 `#e02020` 配淡红底 `#ffe1e1`，不改变尺寸。E2E 直接测量图标中心与区域中心一致。
- 窄窗口限制标签区域占宽，优先保证命令空间；长命令省略显示，完整内容保留在 title 中。

## 两个真实踩过的问题

**选中标签变窄**：`.tag.on` 单独设置 `font-weight:600`，当前字体的数字加粗后反而变窄。真实 E2E 测到“123”宽度从 66.40625px 变为 65.15625px。去掉选中态字重变化，而不是硬编码某个标签宽度。

**悬停标签变成“12 ×”**：绝对定位的删除符遮住“123”最后一位。名称和删除符改为两个独立 flex 子项，删除符固定宽度并禁止收缩；E2E 断言名称右边界不超过删除符左边界，且短标签文字未被截断。

## 完整宿主验收

- 源码：`src/StartupApp.tsx` 与 `src/style.css`；正式入口为 `npm run build` 生成的 `public/index.html`。
- 仿真宿主：`tests/fixtures/rubick-host.html`，复刻 fav 标识、搜索框、三点菜单，用 iframe 加载正式入口，不复制插件 CSS。
- 测试：`tests/visual.e2e.js`，通过 Playwright 请求拦截提供本地文件，注入隔离 db 与假执行。
- 完整窗口包含 1 倍、1.5 倍显示比例；插件内容区另外检查 1200、800、560、375px。
- 截图输出 `.visual-qa/`，已忽略，不提交；包括完整窗口、标签悬停、输入态与两条记录场景。

先运行 `npm run deps` 安装依赖。`npm test` 包含 TypeScript、构建、模型测试与真实浏览器回归；`npm run test:visual` 单独测试当前构建，使用项目的 Playwright 与本机 Edge。

自动检查覆盖：标签选中/取消选中前后所有标签宽度一致、悬停名称与删除符分离、行高固定、列不重叠、无页面横向溢出、新建取消、右键加标签、搜索、keyCode 按键转发、假执行后清空搜索框。

**绿色测试不等于设计验收。** 改 UI 后必须亲自看完整窗口和交互态截图，不能只看插件局部。仿真宿主也不能替代真机 IPC 验证或用户对最终效果的确认。

## Ant Design 组件边界

标签列表使用 Ant Design 配套的 `rc-virtual-list`（36px 固定标签项、6px 自绘滚动条），不使用系统原生滚动条。浮窗锚点按插件 `innerWidth/innerHeight` 与预留面板高度约束在 12px 内边距内，不依赖 Popover 自动翻转；窗口 resize 时同步更新位置和列表高度。底部/右侧打开的完整可见性有浏览器断言。

记录右键打开 `RecordTagPanel`（Ant Design Popover + Input + Checkbox + Button）。标签合并为勾选列表，已关联的排在前面，勾选/取消立即保存且不关闭。标签搜索仅影响面板；输入不存在的名称可以用加号或回车创建并加入。复制、搜索和底部删除固定，只有中间最多 200px 标签列表滚动。面板独立于虚拟行挂载，以记录 ID 读取最新状态；移出当前筛选标签后即使行消失也能继续编辑。Escape 或点击外部关闭；面板打开时禁止全局回车执行命令。

React 管理所有 DOM；Tag/Badge、Button/Tooltip、Input/Space.Compact、Dropdown、Empty 和 message 使用 Ant Design，图标来自 Ant Design Icons。仅列表布局、固定行高、选中背景和标签局部配色保留专用 CSS。顶部可点击 Tag 外包独立 span 作为 Dropdown 的 contextMenu 触发器，避免 Wave 包装层影响事件集成。

Vite 将所有 JS/CSS 内联到单个 HTML；脚本保留 `type="module"`，确保在 head 中执行时等 DOM 解析完成。浏览器回归直接用 file URL 加载产物，不能仅验证开发服务器。
